# 龍序 AI 助手设计

## 目标

在不改变任务、周期任务、关注项目、工作记录和学习记录既有结构的前提下，为龍序增加一个统一的 AI 助手。用户既可以用自然语言查询工作台现有数据，也可以生成新增事项；所有新增操作必须经用户确认后，才调用现有保存接口并参与云端同步。

## 第一版范围

AI 助手支持两类请求：

1. 查询：回答今日、本周、本月范围内的任务、关注项目、周期计划，以及最近的工作和学习记录。
2. 新增：生成普通任务、待办任务、周期任务、关注项目、工作记录或学习记录草稿。

第一版不允许 AI 修改、完成、取消或删除已有数据，不建立任务与关注项目之间的新关联，也不持久化对话历史。

## 交互设计

- 桌面端在右下角展示固定 AI 图标按钮，使用用户提供的红色双龍图片。
- 移动端按钮位于底部导航上方，避免遮挡现有七个导航入口。
- 点击按钮后，桌面端打开右侧助手面板；移动端使用接近全屏的面板。
- 面板包含简短欢迎语、对话内容、单一输入框、发送按钮和关闭按钮。
- 查询结果直接显示文字答案，并标出答案依据的工作台数据类型。
- 新增请求显示结构化确认卡。用户可以确认保存或放弃，确认前不写入任何数据。
- 请求信息不足时，助手只提出一个补充问题，不自行填造关键字段。
- 对话仅保留在当前打开的页面内，关闭或刷新后清空。

## 示例行为

输入：`8.20 日要完成颚破智能化项目的跟踪`

返回任务草稿：

- 标题：跟踪颚破智能化项目
- 日期：2026-08-20
- 优先级：中
- 状态：未开始

输入：`我本周有什么项目？`

返回内容分别汇总：

- 当前未暂停的关注项目及其状态、目标、下一步和复查日期；
- 本周日期范围内的任务；
- 本周到期的周期事项。

助手不会推断任务与关注项目存在数据模型中没有的关联。

## 技术架构

### 客户端

新增独立的 AI 助手功能模块，负责：

- 打开和关闭面板；
- 构建最小化工作区上下文；
- 调用 Supabase Edge Function；
- 校验模型返回的数据结构；
- 展示答案、补充问题或新增草稿；
- 经用户确认后，调用 `WorkspaceProvider` 已有的创建方法保存数据。

查询上下文只包含回答问题所需的结构化字段：任务标题、日期、状态和优先级；关注项目名称、状态、目标、风险、下一步和复查日期；周期计划名称、周期和下次日期；最近记录的日期、标题和摘要。请求设置记录数量和文本长度上限，避免发送整个数据库或超长正文。

### Supabase Edge Function

新增 `ai-assistant` Edge Function：

1. 只接受带有效 Supabase 登录令牌的请求；
2. 检查请求大小和字段格式；
3. 使用服务器密钥调用 DeepSeek 的 OpenAI 兼容接口；
4. 要求模型只返回约定的 JSON 结构；
5. 解析并再次校验结果后返回客户端；
6. 不直接读写龍序数据库。

第一版使用 `deepseek-chat`。配置通过 Supabase Secrets 提供：

- `DEEPSEEK_API_KEY`
- `AI_BASE_URL`，默认 `https://api.deepseek.com`
- `AI_MODEL`，默认 `deepseek-chat`

以后切换 OpenAI 时只更换服务器配置和兼容调用参数，不把 Key 写入 GitHub、GitHub Actions、浏览器存储或聊天记录。

## 响应协议

Edge Function 只返回以下三类结果之一：

- `answer`：基于工作台上下文的只读回答；
- `clarification`：缺少必要信息时的一条补充问题；
- `draft_actions`：一至五个待确认的新增操作。

每个新增操作必须包含明确的类型和与现有输入类型匹配的字段。客户端拒绝未知类型、非法日期、超长文本、无效周期、空标题和超过数量上限的操作。

## 保存与同步

AI 不直接写 Supabase 表。用户确认草稿后，客户端调用现有的：

- `createTask`
- `createRecurringPlan`
- `createFocusProject`
- `createWorkEntry`
- `createLearningEntry`

因此 AI 新增内容与手动新增内容使用相同的本地保存、云端同步、RLS 权限和错误处理逻辑。本功能不需要新增业务表或数据库迁移。

## 安全与隐私

- DeepSeek Key 只保存在 Supabase Secrets。
- Edge Function 要求登录，匿名和本地模式不能调用服务器端 AI。
- 发送给 DeepSeek 的内容限于完成当前请求所需的最小化工作区快照。
- 工作区内容作为数据处理，模型提示明确禁止把记录正文当作系统指令。
- 所有写操作必须由用户确认。
- 第一版不提供删除和修改能力。
- 请求失败、超时或返回非法结构时，不执行任何保存操作。

## 错误状态

- 未登录：提示“登录云端账号后使用 AI 助手”。
- 未配置服务器密钥：提示“AI 助手尚未配置”。
- 网络或模型超时：保留用户输入并允许重试。
- 模型返回非法数据：显示无法处理，不创建任何内容。
- 保存失败：保留确认卡，并沿用工作台现有同步错误提示。

## 测试与验收

- 上下文构建器正确计算上海时区的今日、本周和本月范围。
- 响应校验器接受三种合法响应并拒绝非法字段和未知操作。
- 每类新增草稿都能转换为现有输入类型。
- 查询不会更改工作区数据。
- 新增操作在确认前不保存，确认后通过现有仓库保存并同步。
- 未登录、未配置、超时、非法响应和保存失败都有可恢复提示。
- AI 图标和面板在桌面、Windows 常见宽度及 iPhone 宽度下不遮挡导航。
- 完整 Vitest、ESLint、TypeScript、Next.js 生产构建和 GitHub Pages 静态导出通过。
