# 个人工作台桌面启动器设计

## 目标

在 macOS 桌面提供一个可双击的 `启动个人工作台.command` 文件。用户无需手动输入终端命令，即可启动个人工作台服务器并打开浏览器。

## 启动流程

1. 启动器进入 `/Users/jinlongchen/Desktop/个人平台`。
2. 检查 `http://localhost:3100` 是否已经可访问。
3. 如果工作台已经运行，直接用默认浏览器打开该地址，不再启动第二个服务器。
4. 如果工作台尚未运行，执行 `npm run dev -- --hostname 0.0.0.0 --port 3100`。
5. 循环检查页面，服务器就绪后用默认浏览器打开 `http://localhost:3100`。
6. 终端窗口保持打开，持续显示服务器日志。

## 停止与错误处理

- 用户在启动器终端窗口按 `Control + C` 时，停止开发服务器。
- 如果 Node.js、npm、项目目录或 `package.json` 不可用，显示清晰的中文错误并保留终端窗口，方便查看原因。
- 如果服务器进程在页面就绪前退出，显示启动失败并保留终端窗口。
- 不配置开机自启动，不创建后台常驻服务。

## 文件布局

- 项目内保存可维护的脚本：`scripts/start-workbench.command`。
- 桌面创建同一脚本的符号链接：`~/Desktop/启动个人工作台.command`。
- 脚本设置为可执行；后续更新项目内脚本时，桌面入口自动使用最新版本。

## 验收

- 服务器未运行时，双击图标可启动服务器并打开工作台。
- 服务器已运行时，双击图标只打开浏览器，不产生端口冲突。
- `Control + C` 可停止由启动器启动的服务器。
- 启动器不会修改或删除个人工作台数据。
