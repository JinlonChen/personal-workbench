# 龍序品牌更新设计

## 目标

将个人工作台名称从“一页”更新为“龍序”，以“日日自新，事事有序”为题句，表达通过持续行动重建工作与生活秩序的初衷。

## 展示规则

- 产品名称统一使用繁体“龍序”。
- 浏览器标题使用“龍序 · 个人工作台”。
- 登录页和主导航在产品名称下展示“日日自新，事事有序”，并以古朴的“龍”字印记替换原闪光图标。
- Markdown 导出标题使用“龍序 · 个人工作台导出”。
- README 使用新名称和题句；历史设计文档保留原有名称，作为项目历史记录。
- 设置页版本更新为 `v0.2.1`，版本说明记录品牌升级。

## 边界

本次只调整品牌文案和版本信息，不改变数据结构、同步逻辑、导航结构或任何业务功能。
